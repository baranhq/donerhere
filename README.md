# DönerHere!

DönerHere! is a fictional döner restaurant website I'm building to learn and practice **React** and **TypeScript**.

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Storybook

## Note

DönerHere! is a fictional restaurant made for learning and experimenting. It isn't a real restaurant.
